# Status kelanjutan Syntenthica boot-first

**Diperbarui:** 2 November 2026. **Status:** kandidat 03 untuk perbaikan metadata OTA telah dibangun dan diverifikasi di host; tetap **HOLD / JANGAN FLASH**, belum ada uji perangkat. [Rincian build 03](https://drive.google.com/file/d/16Q4KermKMcxIMHQRTrqkoPgZ74xRB5Cg/view); [ringkasan audit sebelumnya](https://drive.google.com/file/d/19Z4TrJgKINU6XTzozBWXKdhA2ivKP-Cl/view) tetap dipertahankan.

## Keputusan dan batas pengguna

Pengguna menyatakan recovery dan backup aman dan OrangeFox R12.0_2 beta FBEv2 miatoll pernah berhasil dipakai flash. Keterangan ini diterima; jangan meminta konfirmasi ulang. Keberhasilan sebelumnya bukan uji kandidat baru.

Pengguna kemudian menyetujui perbaikan dan build terpisah, termasuk perubahan paket/image yang diperlukan; ini memperbarui pembatasan perubahan paket sebelumnya. Tidak ada persetujuan untuk flash, wipe, format data, pergantian recovery, tindakan pada perangkat atau pelemahan keamanan. Build 03 hanya mengubah dua metadata OTA, bukan image atau policy. Semua modul Magisk/KSU tetap **hold**; fitur dan optimasi menunggu bukti boot dasar.

## Temuan terkini

- [Run build 03, 41477695884](https://github.com/dwp29/Syntenthica/actions/runs/41477695884) berhasil membuat kandidat terpisah; dua metadata OTA sudah ZIP_STORED, dengan offset/ukuran aktual cocok dan protobuf/teks konsisten. Seluruh anggota lain dan compressed stream-nya sama dengan kandidat 02; `unzip -t`, 97 tes host, serta unggah dan unduh ulang tiga bagian lulus. Ini **perbaikan packaging saja**: VINTF dan signature/AVB belum diselesaikan, boot belum diuji, dan kandidat tetap HOLD.
- [Run akhir 41466512890](https://github.com/dwp29/Syntenthica/actions/runs/41466512890) menyelesaikan dua tahap host. Dari 194 executable vendor yang diparsing, 344 pasangan nama/bitness dependency memiliki nama dan header ELF dasar yang cocok pada root terpilih, enam hanya terlihat sebagai symlink, dan 36 tidak terlihat pada root terpilih. Ini bukan pembuktian ABI maupun library hilang. ZIP kandidat dan empat extent tetap utuh.
- Kandidat 02 memiliki komentar ZIP kosong, tidak ada entri `vbmeta*.img`, dan tidak terlihat footer AVB kanonis pada boot/dtbo; offset metadata OTA kandidat 02 tidak cocok. Kandidat 03 memperbaiki kedua offset dan penyimpanan metadata, tetapi masih unsigned dan tidak mengubah boot/dtbo maupun vbmeta. Keadaan vbmeta terpisah, AVB, rollback, enkripsi dan penerimaan recovery pada ponsel tetap tidak diketahui; jangan melemahkan pengaman.
- [Run 41456952143](https://github.com/dwp29/Syntenthica/actions/runs/41456952143) menyelesaikan **54 tes host**, tiga kontrol sintetis, `checkvintf` AOSP dan metadata policy baca-saja. Dua skenario snapshot parsial sama-sama exit **65 / INCOMPATIBLE**; tool melaporkan sepolicy manifest vendor **30.0** tidak memenuhi matriks framework dan tidak menemukan matriks tepat FCM **4**. Workflow sukses berarti audit selesai, **bukan** kandidat lolos; hasil ini tidak membuktikan kegagalan boot. [Rincian audit](https://drive.google.com/file/d/1XIVMCiRAzKnQ0sMFtW40aNY6FTefGm5t/view).
- **Beda dua field policy:** VINTF menyatakan **30.0**, sedangkan `plat_sepolicy_vers.txt` vendor terbaca **31.0**. Mapping `31.0.cil` terlihat di tiga partisi; isi tiga pasangan berkas digest policy platform versus vendor berbeda. Hasil statis ini tidak membuktikan policy yang digunakan atau berhasil dimuat pada perangkat.
- [Run 41460808839](https://github.com/dwp29/Syntenthica/actions/runs/41460808839) menginventarisasi header ELF `vendor/bin` secara baca-saja: **11 ARM 32-bit** menggunakan `/system/bin/linker`, **183 AArch64 64-bit** menggunakan `/system/bin/linker64`, dan satu ARM 32-bit tidak memiliki `PT_INTERP`. Ada 178 symlink yang tidak diikuti. Kedua path linker system adalah symlink ke runtime APEX. [Run 41463290011](https://github.com/dwp29/Syntenthica/actions/runs/41463290011) berhasil membaca payload EROFS terisolasi dan menemukan linker ARM 32-bit serta AArch64 64-bit di dalam paket. Tanda tangan/aktivasi APEX dan kompatibilitas kernel/library tetap belum dibuktikan.
- Audit updater terisolasi sebelumnya lulus **17 skenario lokal**, dan [run 41434731862](https://github.com/dwp29/Syntenthica/actions/runs/41434731862) lulus **7 skenario** pada host. Guard berhenti pada kegagalan yang diuji, tetapi tidak memulihkan penulisan sebelumnya atau parsial. Ini bukan OrangeFox, partisi nyata atau bukti boot.
- [Run 41449702558](https://github.com/dwp29/Syntenthica/actions/runs/41449702558) menyelesaikan inventaris VINTF kandidat kedua dengan hash ZIP dan empat extent cocok sebelum/sesudah. Ada **67 XML** pada empat partisi yang dibaca; **37 tes host** lulus. Tidak ada input image diubah atau diunggah.
- Manifest vendor utama bertarget **FCM 4**; matriks framework berlabel yang terlihat adalah **7, 8, 202404, 202504 dan 202604**, tanpa label 4 pada lokasi yang dibaca. Ada matriks tanpa label di system dan product. Pemeriksaan host parsial berikutnya menghasilkan diagnostik yang disebut di atas, **bukan** vonis gagal atau lulus pada perangkat; pembacaan ODM/APEX/SKU runtime belum lengkap.
- Matriks system tanpa label memuat entri NFC AIDL dan HIDL. Deklarasi NFC HIDL terlihat di vendor; nama/format NFC AIDL tidak ditemukan dalam manifest vendor yang diinventarisasi. Ini bukan bukti NFC atau boot gagal dan bukan pembandingan penuh versi/instance. Lihat [audit VINTF](https://drive.google.com/file/d/1DBQXcWxIPLmgImM99t-MEcXgJ4WoxQLd/view).
- Boot warisan sumber memuat parameter SELinux permissive; analisis init statis menemukan jalur yang dapat memintanya. Ini risiko warisan, bukan perubahan pada kandidat atau bukti status runtime. ZIP tidak memuat vbmeta; AVB eksternal dan penegakannya belum diketahui. [Ringkasan audit AVB/SELinux](https://drive.google.com/file/d/14FqxFcc3wu6TXqeN5k8QMQOaw4Zmirhf/view).
- **Koreksi penyimpanan:** JSON rincian analisis init sempat ada lokal tetapi tidak bertahan saat lingkungan kerja dipulihkan. Provider konektor telah memblokir unggahannya; jangan mengirim ulang atau mengubah kontennya untuk melewati filter. Ringkasan tetap ada di Drive.
- Kandidat 03 hasil repack belum ditandatangani oleh resep; dua offset metadata OTA telah diperbaiki. `dtbo.img` 24 MiB tidak dipotong; ukuran fisik unit pengguna belum diukur. Batas FAT32 untuk satu file lebih kecil daripada ZIP utuh; tidak ada saran memformat media.

## Lanjutkan dengan aman

Build 03 sudah ada, tetapi baru memperbaiki packaging OTA. Lanjutan yang diperlukan untuk ROM boot-first adalah kombinasi framework/vendor dan policy yang benar-benar kompatibel serta validasi signature/AVB yang sah; jangan sekadar mengganti angka deklarasi kompatibilitas. Pertahankan sumber, ketiga kandidat dan backup. Tidak ada pengujian atau tindakan pada perangkat; tindakan flash, wipe, atau pelemahan keamanan tidak disetujui.
