## Yang harus diperbaiki sebelum dianggap "selesai"

1. **Belum pernah di-flash. Tidak ada satu pun bukti boot.**
2. **MGLRU/UCLAMP/WALT hanya muncul 2–3 kali** di Image, sedangkan SuSFS 142 kali.
   Jumlah itu rendah untuk fitur yang mengklaimnya — perlu dipastikan kodenya
   benar-benar aktif, bukan sekadar nama simbol tersisa di tabel string.
3. **`-Os` bukan `-O2`.** Build memakai `CONFIG_CC_OPTIMIZE_FOR_SIZE=y` karena `-O3`
   memicu `-mcpu=cortex-a55` yang ditolak clang. 3.2 dibangun dengan `-O2`.
4. **`can_umount` dan `path_umount` ditambal manual**, karena sed milik
   KernelSU-Next tidak berjalan di pohon ini.
5. **Dua sysctl WALT (`sysctl_sched_conservative_pl`, `sysctl_sched_many_wakeup_threshold`)
   adalah bug bawaan Kinesis** — didaftarkan di `kernel/sysctl.c` tapi tidak
   didefinisikan di mana pun. Ditambal kosong (tanpa default), jadi nilainya 0.
6. **Performance / stability / no drain / no hot / deep sleep belum diukur sama sekali.**
   Itu butuh perangkat dan angka, bukan build yang hijau.

## Yang penting untuk diketahui projekt

Roll 3.3 **tidak pernah punya** MGLRU, UCLAMP, atau WALT. Saat Image-nya dibuka:

```
MGLRU 0 · UCLAMP 0 · WALT 0 · KernelSU ada · SuSFS 143 · NoMount 14
```

Artinya fitur "Synthetica" yang selama ini dikira ada di Roll 3.3 ternyata tidak
pernah ikut dikompilasi ke sana. UFO-0.1 adalah build pertama yang benar-benar
membawa ketiganya.
