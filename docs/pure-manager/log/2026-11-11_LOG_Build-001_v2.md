untuk ditulis.**

Keduanya baru ketahuan setelah APK-nya dibongkar, bukan dari status CI.

### APK-nya tidak bisa dipasang

tidak ada sertifikat. Status "success" menyesatkan: tidak ada perangkat yang mau

tidak pernah di-import.

**42 MB → 18 MB.** Yang tersisa di dex (17 MB) adalah Compose + Material3 itu
sendiri, bukan kode aplikasi.
