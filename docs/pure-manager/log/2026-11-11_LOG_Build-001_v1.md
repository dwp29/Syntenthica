## 2. Keputusan teknis yang diambil

1. **`NavModel` masuk token, bukan di luar.** Kalau model navigasi hanya dipilih
   di `MainActivity`, layar akan bercabang pada id tema. Sekarang `PureShell`
   membaca `spec.nav`.
2. **`minSdk 29`, `targetSdk 36`.** Android 17 belum punya SDK stabil.
3. **Izin storage tidak diminta.** Build yang belum bisa membaca berkas tidak
   pantas meminta akses semua berkas.
4. **Tema disimpan di `saveable`, bukan DataStore.** Format token masih bergerak;
   menyimpan sekarang berarti migrasi minggu depan.
5. **Tidak ada library berat.** libsu, docx4j, sora-editor, FFmpeg masuk di
   tahap yang membutuhkannya.

## 3. Kegagalan build — dicatat, bukan dihapus

menolak di bawah 8.9.

### Build #3 — run `42957974385` — GAGAL

`gh run download` juga mengembalikan **EOF** untuk artifact. Jadi baik log maupun

pesan compiler. Yang bisa saya lakukan:
