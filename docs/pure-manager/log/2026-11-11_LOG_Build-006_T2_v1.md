## 2. Dua jalur izin

Android terus menutup jalur yang baik, jadi ada dua:

**Semua Berkas** (`MANAGE_EXTERNAL_STORAGE`) — akses `File` sungguhan. User
menyalakannya di Setelan Android. Ini yang membuat aplikasi bisa **mengubah**
berkas, bukan sekadar melihat.

**SAF** — tanpa izin khusus, user memilih folder. Berfungsi di semua versi.

Manifest kini meminta izinnya — dan tes menegaskan **izin dan kemampuan tidak
boleh terpisah**: tahap 1 tidak minta karena tidak bisa memakainya, tahap 2 minta
karena sekarang memakainya.

## 3. Tiga bug sungguhan yang ditemukan tes JVM

Ini bagian terpenting. Bukan "tes lolos", tapi **tes menemukan kode yang salah**:

### 3.1 Salin folder ke dirinya sendiri

```kotlin
// SEBELUM: hanya menolak tujuan DI DALAM sumber
if (src.isDirectory && dir.absolutePath.startsWith(src.absolutePath + separator))
```

`copy(folder, folder)` lolos pemeriksaan → rekursi → **disk penuh**. Sekarang
identitas diperiksa lebih dulu, untuk `copy` dan `move`.

### 3.2 Aturan spasi yang tidak pernah bisa menyala

```kotlin
val trimmed = name.trim()                          // spasi sudah dibuang
if (trimmed.endsWith(" ")) return "...spasi"       // tidak akan pernah benar
```

`"nama "` diterima diam-diam. Baris itu **terlihat seperti penjaga, tapi tidak
menjaga apa pun**. Sekarang spasi diperiksa pada string asli, sebelum di-trim.

### 3.3 Tes yang tidak bisa dikompilasi

`"a\\\\b"` di dalam `listOf` adalah dua karakter; Kotlin butuh char literal satu
karakter. Tesnya **tidak pernah menguji apa pun**.

Bagian ini perlu dicatat karena bukan soal kode.

## 8. Yang perlu Anda coba

1. Buka **Berkas** → muncul kartu izin
2. Tekan **Beri izin "Semua berkas"** → nyalakan di Setelan Android → kembali
3. Harusnya muncul daftar folder asli: `Android`, `DCIM`, `Download`, dll.
4. Masuk ke `Download` → **tahan/tekan ⋯** pada satu berkas → Ganti nama / Salin /
   Pindah / Hapus / Info
5. Tekan **+** → Folder baru
6. Tombol kanan atas → sortir, grid/daftar, berkas tersembunyi, home

Kalau ada yang salah, **Setelan → Laporan crash → Salin**.
